# Sharair Portfolio

Personal portfolio website for **Mohammed Sharair All Mamun** — High-Purity Piping Specialist & Orbital Welding QA/QC Technician.

Live landing page featuring an interactive 3D UHP gas-distribution scene (React Three Fiber), experience timeline, project case studies, skills matrix, and contact.

## Stack

- **Next.js 14** (App Router) · TypeScript · Tailwind CSS · shadcn/ui
- **React Three Fiber / three.js** — interactive 3D piping & cleanroom scenes
- **Framer Motion** — animations
- **Prisma** (PostgreSQL) · **next-auth** (Google/LinkedIn) · **Supabase** — auth & data (WIP)
- **OpenRouter / Google AI** — AI assistant (WIP)

## Getting started

```bash
npm install
cp .env.example .env   # fill in values — never commit real keys
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
